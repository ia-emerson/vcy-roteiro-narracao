# Projeto Roteiro + Narração

- Roteiros: use a skill `roteiro_vcy` (regras em `comando.txt`, saída em `roteiros/`).
- Narração: use a skill `narracao_vcy` (OmniVoice local, vozes em `voices/`, saída em `narrações/`).
- Fluxo: tópicos → aprovação → roteiro → aprovação → pergunta sobre narração → narração.
- Python do projeto: `.venv\Scripts\python -m narrador ...` (Windows) ou `.venv/bin/python` (Mac/Linux).
  Se `.venv` não existir, peça para rodar `instalar.ps1` / `instalar.sh`.
